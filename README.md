# POWER Car — Landing

Лендинг для компании по импорту автомобилей из Китая, Японии и Кореи.

## Стек

- HTML5 / CSS3 / Vanilla JS
- Шрифты: Bricolage Grotesque + Manrope (Google Fonts)
- Дизайн: liquid glass / iOS 26
- Без сборщиков, без зависимостей — один HTML-файл

## Запуск локально

Просто открой `index.html` в браузере. Никакой сборки не требуется.

```bash
# или через простой HTTP-сервер
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Что внутри

- **Header** — sticky с liquid glass, кнопка заявки
- **Hero** — ротация стран (Китая → Японии → Кореи), статистика, паралакс-карточки
- **Этапы работы** — 4 карточки с 3D tilt на hover
- **Калькулятор** — расчёт стоимости под ключ (упрощённая формула, помечена как demo)
- **Виджет рекомендаций** — top-5 авто по бюджету (фильтр ±15%, сортировка по приоритету)
- **Кейсы клиентов** — горизонтальный scroll-snap слайдер
- **FAQ** — нативный аккордеон через `<details>`
- **Финальный CTA** — форма заявки с маской телефона, согласие 152-ФЗ
- **Mobile FAB** — кнопка Telegram внизу экрана на мобильных
