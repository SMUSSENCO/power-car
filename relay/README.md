# Приём заявок: сайт → Telegram + MAX

Сайт отправляет заявку на нашу функцию в Яндекс Облаке, а она пересылает её в Telegram и в MAX.
Токены ботов хранятся только в настройках функции — в репозитории и на сайте их нет.

## Что нужно сделать один раз (≈ 20 минут)

### 1. Новый токен Telegram-бота
Вы уже отозвали старый. В @BotFather: `/mybots` → ваш бот → **API Token** → скопируйте новый токен. Никому не отправляйте.

### 2. MAX-бот
1. В MAX откройте @MasterBot → `/newbot` → задайте имя и ник → скопируйте токен.
2. Создайте в MAX группу для заявок («Заявки POWER Car») и добавьте туда бота (как администратора, чтобы он мог писать), а также менеджеров.

### 3. Функция в Яндекс Облаке
1. Откройте <https://console.yandex.cloud>, войдите под своим Яндекс-аккаунтом, создайте облако и платёжный аккаунт (нужна карта; наша нагрузка — в бесплатном лимите, это копейки или 0 ₽).
2. Слева **Cloud Functions → Создать функцию**. Имя: `lead-relay`.
3. **Среда выполнения:** Node.js 22 (или 18). Способ создания — «Редактор кода». Файл `index.js` — вставьте содержимое `relay/yandex-function/index.js` из этого репозитория. **Точка входа:** `index.handler`. Тайм-аут 15 секунд, память 128 МБ.
4. **Переменные окружения** (все значения — без кавычек):

   | Имя | Значение |
   |---|---|
   | `TG_BOT_TOKEN` | новый токен Telegram-бота |
   | `TG_CHAT_ID` | `-1003891049696` |
   | `MAX_BOT_TOKEN` | токен MAX-бота |
   | `MAX_CHAT_ID` | id группы в MAX (см. ниже) |
   | `DIAG_KEY` | любая случайная строка, например `k7Qp29xLm` (нужна один раз для поиска `MAX_CHAT_ID`) |

5. **Создать версию.** Затем во вкладке «Обзор» включите **«Сделать функцию публичной»** и скопируйте **ссылку для вызова** (`https://functions.yandexcloud.net/…`).
6. Пришлите мне эту ссылку — я подключу её к сайту.

### Как узнать `MAX_CHAT_ID`
Сначала создайте функцию без `MAX_CHAT_ID`, сделайте её публичной и откройте в браузере:
`ССЫЛКА_ФУНКЦИИ?diag=ВАШ_DIAG_KEY` — в ответе будет список чатов бота с `chat_id`. Впишите нужный в переменную `MAX_CHAT_ID` и создайте новую версию.

### 4. Проверка
После того как я подключу ссылку и вы нажмёте Push, отправьте тестовую заявку с сайта — она должна прийти и в Telegram, и в MAX.
В логах функции (вкладка «Логи») видно `{"lead":true,"tg":true,"max":true}` — какой канал сработал.

## Безопасность
- Принимаются запросы только с `https://power-car.ru` и `https://www.power-car.ru`.
- Заявка без отметки согласия отклоняется; заполненное скрытое поле (бот) отбрасывается; не больше 6 заявок в минуту с одного адреса.
- Если токен когда-либо утечёт — отзовите его у BotFather/MasterBot и замените в переменных окружения, код сайта менять не нужно.
