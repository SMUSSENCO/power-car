POWER Car — обновление: гео-страницы + динамическая страница авто.

ЧТО КУДА (всё в КОРЕНЬ репозитория, с заменой):
  index.html, car.html, sitemap.xml, robots.txt   -> корень
  avto-iz-yaponii-tomsk/novosibirsk/moskva.html    -> корень
  data/offices.json                                -> в существующую папку data/ (заменить только этот файл)
  scripts/gen_geo.py                               -> корень (для пересборки гео-страниц)

СТРАНИЦЫ АВТО:
  Отдельные файлы НЕ нужны. car.html — динамический шаблон: открывается как
  car.html?id=ID_АВТО и сам берёт данные из data/cars.json.
  Новое авто из админки -> новый cars.json -> push -> страница работает сразу.
  Проданное авто (удалено из cars.json) -> страница покажет "нет в наличии".
  Чистить ничего не нужно.

ГЕО-СТРАНИЦЫ:
  Если поменяли офисы/каталог и хотите обновить 3 гео-страницы:
    python3 scripts/gen_geo.py   (запускать из корня, где лежит data/)

SITEMAP:
  Список авто в sitemap.xml можно обновлять периодически (не обязательно при
  каждом авто — Яндекс/Google всё равно находят car.html по ссылкам с гео-страниц
  и каталога). Для полноты — пересоберите при крупных изменениях каталога.
